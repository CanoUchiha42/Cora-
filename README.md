# Cora AI — ACE AI AGENTS

Premium, statische Marketing-Website für Cora AI.

## Warum statisch?
Die Seite ist bewusst ohne kostenpflichtiges Framework-Hosting gebaut. HTML, CSS und JavaScript können kostenlos über GitHub Pages ausgeliefert werden.

## Dateien
- index.html — Landingpage
- styles.css — Designsystem und responsive UI
- app.js — Demo, Navigation und Lead-Formular
- impressum.html — technische Vorlage
- datenschutz.html — technische Vorlage

## Lead-Formular
Das Formular sendet an den konfigurierten Google Apps Script Web-App-Endpunkt. Vor dem produktiven Einsatz sollte ein Testlead erzeugt und im Google Sheet kontrolliert werden.

## GitHub Pages
Repository Settings → Pages → Deploy from a branch → main → / (root) → Save.

## Wichtig vor dem öffentlichen Geschäftsbetrieb
Impressum und Datenschutzerklärung müssen mit den echten Anbieter- und Verarbeitungsdaten vervollständigt und rechtlich geprüft werden.
